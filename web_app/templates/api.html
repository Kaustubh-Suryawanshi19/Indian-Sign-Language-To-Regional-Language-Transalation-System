Local API Documentation

The Flask demo exposes a small JSON API around the local webcam detector.

GET /health

Returns model, Gemini, and camera status.

GET /api/process

Returns the current gesture sequence and detection state.

POST /api/toggle_detection

Starts or stops the local camera worker.

POST /api/reset

Clears the temporal sequence.

POST /api/translate

Request body:

{
  "signs": ["I", "Love", "Home"],
  "lang": "mr"
}

The server validates the sequence, localizes known tokens, and then uses Gemini when configured. If Gemini is unavailable, a deterministic fallback is returned.

Response

{
  "status": "success",
  "translation": "मला घर आवडते.",
  "language": "Marathi",
  "localized_tokens": ["मी", "प्रेम", "घर"],
  "method": "gemini"
}

Deployment note

This prototype reads the webcam attached to the Flask host. It is not a remote browser-camera API. Use WebRTC/WebSocket camera capture for a multi-user deployment.
